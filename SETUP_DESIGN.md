# Дизайн собственного Veles Setup

## Внешний вид

Setup должен выглядеть как часть сайта Veles, а не как стандартный мастер Inno Setup. Используется окно 760×460 с тёмным графитовым фоном, плоской панелью контента, оранжевым логотипом V, крупным названием продукта, спокойными подписями и одной заметной оранжевой кнопкой действия. Стеклянные панели, градиенты, перегруженные шаги и мелкий текст не используются.

## Сценарий игрока

При запуске Setup он показывает название пакета, текущую установленную версию и версию пакета. Если приложение уже установлено, основной текст говорит «Обновление Veles Launcher» или «Обновление Veles Build Publisher», а действие — «Обновить». Если установки нет, показывается «Установка» и действие «Установить».

Setup проверяет, что целевой процесс не запущен. Если Launcher или Publisher открыт, он показывает «Закройте приложение перед обновлением» и кнопку повторной проверки. После закрытия Setup копирует файлы во временную папку, создаёт резервную копию, заменяет приложение атомарно, создаёт ярлык и удаляет резервную копию только после успеха. При ошибке старая рабочая версия восстанавливается.

## Два пакета

Публичные файлы сохраняют понятные имена `VelesLauncherSetup.exe` и `VelesBuildPublisherSetup.exe`, но теперь это собственный Veles Setup с разными встроенными payload-манифестами. Главный пакет содержит Launcher, Updater и Core. Второй пакет содержит Publisher и Core. Отдельного updater setup нет.

## Автообновление

`Veles.Updater.exe` скачивает `VelesLauncherSetup.exe` из публичного GitHub Release и передаёт Setup режим обновления. Setup определяет существующую папку, версию и заменяет только файлы Launcher-пакета. Установленный Launcher не запускается вторым экземпляром поверх старого процесса.
