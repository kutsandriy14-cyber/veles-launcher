# Veles Launcher — отчёт проверки

Дата: 2026-08-27.

## Проверено успешно

| Область | Результат |
|---|---|
| C# WinForms-проекты | Сборка прошла на Windows runner для Veles.Core, Veles Launcher, Veles Build Publisher и Veles Launcher Updater. |
| Логика Core | Тесты подтвердили разбор UTF-8 TXT с BOM и комментариями, сравнение версий, отклонение порта вне диапазона и запись имени/IP в `servers.dat`. |
| Установка сборки | Код скачивает `build.zip`, проверяет SHA-256, распаковывает во временный каталог и атомарно заменяет инстанс. |
| Блокировка устаревшей сборки | Запуск блокируется, если локальная версия ниже последнего `BUILD_VERSION`. |
| Репозиторий сборок | Клиент читает только последний публичный GitHub Release из `veles-modpack-releases`. |
| Админ-панель | Отдельный C# EXE формирует `build-info.txt`, считает SHA-256, создаёт release и загружает `build.zip` и TXT. Токен не сохраняется. |
| Updater | Отдельный C# EXE ищет `VelesLauncherSetup.exe` в последнем релизе `veles-launcher`. |
| Setup | Inno Setup успешно создал три установщика с разными AppId, каталогами и ярлыками. Основной VelesLauncherSetup дополнительно кладёт отдельный `Veles.Updater.exe` рядом с Launcher; каждый setup проверяет .NET Framework 4.8. |
| Публичные репозитории | Оба репозитория публичные, ветка `main`, без незакоммиченных изменений. |

## Артефакты

`VelesLauncherSetup.exe`, `VelesBuildPublisherSetup.exe` и `VelesLauncherUpdaterSetup.exe` опубликованы в [релизе v0.1.2](https://github.com/kutsandriy14-cyber/veles-launcher/releases/tag/v0.1.2).

## Ручная проверка, которая понадобится после получения настоящей сборки

Второй репозиторий пока содержит только документацию и пример конфигурации, потому что настоящий `build.zip` сборки не был передан. После его подготовки через отдельную админ-панель нужно опубликовать релиз с `build.zip` и `build-info.txt`, затем один раз проверить установку на Windows 7–11 и запуск `LAUNCH_COMMAND`. Без настоящего игрового архива нельзя честно подтвердить запуск конкретной Forge-сборки.

## Важно

Лаунчер не создаёт фиктивные аккаунты Minecraft и не подменяет авторизацию. Если сервер работает в online-mode, стартовый файл сборки должен запускать клиент с корректной реальной авторизацией Microsoft или другой разрешённой сервером схемой.
