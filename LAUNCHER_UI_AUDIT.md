# Аудит реального Veles Launcher

## Проблемы, видимые пользователю

На реальном снимке Launcher окно выглядит слишком маленьким для длинных русских подписей. Верхние кнопки «Настройки», «Обновить Launcher» и «Сайт сервера» сжаты, часть текста режется. Карточка сборки имеет недостаточную ширину: заголовок и кнопка обновления упираются в границы и визуально ломают композицию. Окно настроек открывается поверх главного без достаточного отступа и также режет путь и элементы управления.

Главная причина — смешение абсолютных координат, фиксированных ширин и автоматической компоновки без расчёта минимальных размеров. Для WinForms нельзя одновременно рассчитывать на широкий динамический текст и маленькое фиксированное окно.

## Требования к исправлению

Главное окно должно иметь минимум 1180×760 и корректно масштабироваться при увеличении. Верхняя панель должна содержать логотип отдельно, а кнопки — в отдельной правой колонке с переносом или достаточной минимальной шириной. Заголовок сборки должен быть ограничен по ширине и переноситься максимум на две строки без выхода за границы.

Основной экран должен использовать две одинаковые карточки с внутренними TableLayoutPanel/FlowLayoutPanel, без ручного размещения кнопок по координатам. Кнопки должны иметь минимальную ширину, а длинные русские статусы — AutoEllipsis или перенос внутри выделенной строки. Настройки должны открываться как отдельное фиксированное диалоговое окно нормального размера, не перекрывая смыслом главный экран, с широким полем пути и понятной кнопкой выбора.

Текущая серверная логика, автообновление, Java и прямой запуск не меняются в этом этапе. Меняется только пользовательская компоновка и читаемость интерфейса.
