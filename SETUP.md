# Установка Veles-программ

В репозитории опубликованы два установщика. `VelesLauncherSetup.exe` устанавливает пользовательский лаунчер, `Veles.Updater.exe` и `Veles.Core.dll` рядом в одной папке. `VelesBuildPublisherSetup.exe` устанавливает полностью отдельную админ-панель. Отдельного `VelesLauncherUpdaterSetup.exe` нет и быть не должно: Updater входит только в основной установщик.

Каждый setup использует собственный AppId и папку в `%LOCALAPPDATA%\Programs`. Админ-панель не включается в клиентский лаунчер, а GitHub-токен не записывается в клиент и публичные файлы. Оба установщика проверяют наличие .NET Framework 4.8.

## Первый запуск игрока

Установите `VelesLauncherSetup.exe` и откройте Veles Launcher. Нажмите «Проверить и обновить сборку». Клиент скачает последний публичный релиз из `kutsandriy14-cyber/veles-modpack-releases`, проверит `build-info.txt` и SHA-256 архива, распакует сборку встроенными средствами .NET и добавит сервер в `servers.dat`.

В архиве уже лежит совместимый Java runtime. После установки лаунчер использует `runtime\java\bin\javaw.exe` или `java.exe` внутри экземпляра. Поэтому игроку не нужно отдельно ставить Java, 7-Zip, Forge или выполнять команды в консоли. Кнопка запуска остаётся заблокированной, пока сборка отсутствует, устарела или опубликована неполностью.

В пункте «Настройки» доступны папка экземпляра и минимальный/максимальный объём RAM. Они сохраняются локально в `%AppData%\Veles Launcher\settings.json`.

## Публикация сборки администратором

Установите `VelesBuildPublisherSetup.exe`, выберите готовый `build.zip`, укажите название, версию сборки, Minecraft, версию модлоадера, единый адрес `IP:PORT`, название сервера и параметры Java. Список модлоадеров ограничен `Forge`, `Fabric`, `Quilt` и `NeoForge`; произвольный текст не принимается.

Перед публикацией панель проверяет, что ZIP содержит `launch.json` и встроенную Java по пути `runtime\java\bin\javaw.exe` либо `java.exe`. Панель сама создаёт `build-info.txt`, рассчитывает SHA-256 архива и загружает оба файла в новый GitHub Release. В конфигурации нет `LAUNCH_COMMAND`, `start.bat`, IP и порта отдельными полями или произвольных shell-команд.

Профиль `launch.json` должен содержать валидированные параметры прямого запуска: `mainClass`, `classPath`, а также безопасные `jvmArguments` и `gameArguments` без запуска `cmd.exe`, `.bat` или внешних командных оболочек.

## Обновление самого лаунчера

Для обновления приложения запустите `Veles.Updater.exe` из папки Veles Launcher. Он сравнит встроенную версию с последним релизом `kutsandriy14-cyber/veles-launcher`, найдёт asset с точным именем `VelesLauncherSetup.exe`, скачает установщик и запустит его. Updater не является обновлятором Minecraft-сборки: сборка обновляется внутри главного Veles Launcher.

Последний ранее проверенный стабильный релиз: [Veles Launcher v0.1.5](https://github.com/kutsandriy14-cyber/veles-launcher/releases/tag/v0.1.5). Новая версия не считается проверенной до успешного Windows CI и проверки состава установщиков.
