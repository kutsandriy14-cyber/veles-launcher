# Установка Veles-программ

В репозитории опубликованы три установщика. `VelesLauncherSetup.exe` устанавливает пользовательский лаунчер и отдельный `Veles.Updater.exe` рядом с ним в одной папке. `VelesBuildPublisherSetup.exe` устанавливает полностью отдельную админ-панель для публикации сборок. `VelesLauncherUpdaterSetup.exe` остаётся отдельным опциональным установщиком Updater для случаев, когда его нужно установить отдельно.

Каждый setup использует собственный AppId и собственную папку в `%LOCALAPPDATA%\Programs`. Админ-панель не включается в клиентский лаунчер, а GitHub-токен не записывается в публичные файлы. В основной папке Veles Launcher находятся `Veles.Launcher.exe`, `Veles.Updater.exe` и общий `Veles.Core.dll`; это два самостоятельных EXE, а не объединённая программа. Все три установщика проверяют наличие .NET Framework 4.8.

## Первый запуск пользователя

Установите Veles Launcher. Нажмите «Установить / обновить сборку». Клиент скачает последний релиз из `kutsandriy14-cyber/veles-modpack-releases`, проверит `build-info.txt`, проверит SHA-256 архива `build.zip`, распакует сборку и добавит IP:порт в `servers.dat`. Если локальная версия ниже последнего релиза, кнопка запуска остаётся заблокированной до обновления.

## Публикация сборки администратором

Установите Veles Build Publisher, выберите готовый `build.zip`, заполните название, версию сборки, версию Minecraft, модлоадер, его версию, IP и порт. Панель сама создаст `build-info.txt`, рассчитает SHA-256 архива и загрузит оба файла в новый GitHub Release репозитория сборок. Для публикации нужен Fine-grained Personal Access Token с правом `Contents: Read and write` только для репозитория `veles-modpack-releases`; токен используется только в памяти панели.

Архив должен содержать подготовленный игровой инстанс и `start.bat` либо другой файл, указанный в поле `LAUNCH_COMMAND`. Для серверов с авторизацией Microsoft стартовый файл должен запускать подготовленный клиентский профиль с корректным способом авторизации; лаунчер не подставляет фиктивные аккаунты.

## Обновление самого лаунчера

Запустите Veles Launcher Updater. Он сравнит встроенную версию с последним релизом `kutsandriy14-cyber/veles-launcher` и ищет asset с точным именем `VelesLauncherSetup.exe`. При наличии более новой версии он скачает установщик, запустит его и завершит работу старого обновлятора.

Актуальный проверенный релиз: [Veles Launcher v0.1.3](https://github.com/kutsandriy14-cyber/veles-launcher/releases/tag/v0.1.3).
