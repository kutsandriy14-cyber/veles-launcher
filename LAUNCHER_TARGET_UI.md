# Целевой интерфейс Veles Launcher

Реальный Launcher должен повторять ранее показанное превью, а не фотографию старой сборки.

## Структура окна

Окно широкое, около 1180×760, с тёмным графитовым фоном и плоскими прямоугольными карточками. В верхней полосе слева находится компактный логотип V и надпись `VELES PLAYGAME / SERVER LAUNCHER`. Справа находятся одинаковые аккуратные кнопки `Настройки`, `Обновить Launcher` и `Сайт сервера`.

Под шапкой расположен hero-блок. Слева показывается крупное динамическое название сборки, например `TerraFirmaGreg: Modern`, ниже подпись `СЕРВЕРНАЯ СБОРКА` и версия. Название берётся только из latest release и должно переноситься, не обрезаться и не выходить за пределы блока.

Основная область состоит из двух одинаковых карточек. Левая карточка называется `ПОДКЛЮЧЕНИЕ К СЕРВЕРУ`, содержит динамический адрес одной строкой `IP:PORT` и кнопку `Копировать`. Правая карточка называется `СБОРКА И ОБНОВЛЕНИЕ`, содержит динамическое имя сборки, строки `Minecraft ... · Forge ...`, кнопки `Проверить обновления` и `Запустить Minecraft`, а также прогресс загрузки.

Внизу расположен широкий блок из трёх равных колонок: `МОДЛОАДЕР`, `ВЕРСИЯ MINECRAFT`, `СТАТУС`. Цветовые акценты — оранжевые, неактуальная или отсутствующая сборка показывает спокойный нейтральный текст и отключённую кнопку запуска.

## Иконки

В карточке сервера используется оранжевая иконка подключения, в карточке сборки — оранжевая иконка куба/архива, у обновления — иконка циклических стрелок, у запуска — play-иконка, в настройках — шестерёнка. Иконки должны быть небольшими, единообразными и не заменять текст кнопок.

## Запреты

Не использовать стеклянные панели, наклонённые градиенты, мелкие фиксированные поля, наложение SettingsForm поверх главного layout, обрезание длинных русских надписей, жёсткое название TerraFirmaGreg в коде, отдельные IP/PORT-поля или технический API error в пользовательском состоянии.
